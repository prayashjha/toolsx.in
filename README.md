# ToolsX Blogger Theme Backup

This repository contains a raw backup of the Blogger XML theme for **ToolsX – Free Online Tools Hub**, exported directly from Blogger's Theme editor (Backup Theme).

## File
- `theme-7190386619628557741.xml` — the complete, unmodified Blogger theme XML (includes layout, widgets, CSS, and scripts). File content has not been changed in any way.

## Purpose
This is kept here purely for **version control / backup**. It is a Blogger-specific template (uses `b:section`, `b:widget`, `data:blog.*` tags etc.) and will only work correctly when restored back into Blogger's Theme editor — it is **not** a standalone static website.

## How to restore
1. Go to Blogger Dashboard → Theme → Edit HTML (dropdown) → Revert to a saved theme / Restore
2. Upload this `.xml` file
